# SemTS：时序数据"通用语义"预训练模型 —— 设计方案 v0.1

> 项目目标：设计并实现一个**论文级**自监督预训练方法（单卡 8–24GB 可训练），
> 把"通用时序语义"的 7 个维度归纳为 **4 条可消融的预训练"语义流"**，
> 首次同时**显式**建模 ⑤ 跨通道滞后/因果 与 ⑦ 缺失/质量 两类被主流预训练忽视的语义。
>
> 下游任务：预测（forecasting）、分类（classification）、异常检测（anomaly detection）、零样本/跨域迁移。
> 配套文档：`E:\PycharmProgram\Atricles\Time Series Forecastinng\PreTrain\时序预训练_语义映射与研究选题.md`

## 1. 语义 → 模块映射（本设计的核心）

| 语义维度 | 预训练流（Stream） | 具体任务 / 损失 | 技术来源 |
|---|---|---|---|
| ① 时间（多粒度/顺序） | **S1 层级对比头** | 时序对比 + 实例对比（maxpool 多尺度） | TS2Vec |
| ③ 实体（实例/多变量） | **S1**（共用） | 实例判别（instance-wise contrast） | TS2Vec |
| ④ 模式（趋势/季节/频域） | **S2 模式头** | 趋势解耦（时域对比）+ 季节解耦（频域幅值/相位对比） | CoST |
| ⑤ 关系（跨通道滞后/因果） | **S3 关系头**（★创新） | 滞后软回归 + 领先方向判别（自监督弱标签） | 新任务 |
| ⑦ 质量（缺失/置信度） | **S4 质量头**（★创新） | 三态掩码重建 + 质量等级预测 | 新任务（TimesURL 重建的扩展） |
| ⑥ 事件/状态 | —（v0.1 不纳入，见 §9 二期扩展） | — | — |

设计原则：**每个语义维度对应一个独立、可单独开关/消融的模块**，论文的消融实验即为"逐条移除语义流"。

## 2. 总体架构

```
                        ┌─────────────────────────────────────────────────┐
  x ∈ R^(L×C) ──► 视图构造（掩码/裁剪 + scale/shift/jitter + 三态质量掩码）   │
                        └──────────────────┬──────────────────────────────┘
                                           ▼
                      ┌─────────────────────────────────────────────┐
                      │  骨干编码器（共享，参数 ~2–4M）                │
                      │  Patch Embedding(16, stride 8)               │
                      │  + Channel-Independent Transformer(L=4,d=256) │
                      └───┬──────────┬──────────┬──────────┬─────────┘
                          ▼          ▼          ▼          ▼
                      ┌───────┐ ┌────────┐ ┌────────┐ ┌─────────────┐
                      │  S1   │ │  S2    │ │  S3    │ │  S4         │
                      │层级对比│ │模式头  │ │关系头  │ │质量头       │
                      │①③     │ │④      │ │⑤      │ │⑦           │
                      └───┬───┘ └───┬────┘ └───┬────┘ └──────┬──────┘
                          ▼          ▼          ▼             ▼
                     L_hier      L_pat     L_rel        L_qual
                          └──────────┴──────────┴─────────────┘
                                    总损失 L（自适应权重）
```

- **骨干**：通道独立（channel-independent）Transformer——每个通道独立编码，天然支持任意通道数，
  是 ③ 实体语义与零样本跨域（不同通道数的数据集可共享骨干）的关键设计（SimMTM 同款动机）。
- **表示**：主干输出逐时间戳表示 `z ∈ R^(L'×C×d)`；S1 取时间戳/实例级，S2 取趋势/季节双流，S3 取通道级摘要，S4 走轻量解码器。

## 3. 四个语义流详细设计

### 3.1 骨干编码器
- 输入：多变量序列 `x ∈ R^(L×C)`，默认 `L=336, C≤21`。
- Patch embedding：`Conv1d(patch=16, stride=8)` + 可学习位置编码，逐通道共享。
- Transformer encoder：`L=4, d_model=256, heads=8`，通道独立（同一权重处理所有通道）。
- 视图构造（按流各取所需）：
  - **S1 用**：隐向量级时间戳掩码（p=0.5）+ 随机裁剪，两个重叠上下文视图（TS2Vec 式"上下文一致性"正对）；
  - **S2 用**：scale / shift / jitter 增强（CoST 式"误差变量干预"）；
  - **S3 用**：原始主视图（不做破坏性增强）；
  - **S4 用**：三态质量掩码（见 3.4）。

### 3.2 S1 层级对比头（① 时间 + ③ 实体）
- 时序对比损失：同一时间戳在两个增强视图中的表示互为正，同序列其他时刻为负；
- 实例对比损失：同实例跨视图互为正，batch 内其他实例为负；
- 多尺度：`maxpool(k=2)` 逐层收缩表示，各尺度损失累加（TS2Vec 层级对比）。
- 覆盖语义：① 时间（任意粒度：时间戳/子段/实例）、③ 实体（实例判别）。

### 3.3 S2 模式头（④ 趋势/季节）
- **TFD 趋势解耦器**：`L+1` 个因果卷积专家（核 `2^i`，`i=0..L`）混合 + 平均池化 → 趋势表示；
  时域对比损失（MoCo 队列）。
- **SFD 季节解耦器**：`FFT → 逐频率复值线性层（频内交互）→ iFFT` → 季节表示；
  频域对比损失 = 幅值项 + 相位项（避免人工设定周期）。
- 增强：scale/shift/jitter（模拟对误差变量的干预，学不变表示）。
- 覆盖语义：④ 模式（趋势-季节显式解耦、频域谱、非平稳鲁棒）。

### 3.4 S3 关系头（⑤ 跨通道滞后/因果）★创新点
- **自监督弱标签生成**（预训练时计算，可缓存）：
  1. 对每对通道 `(i,j)` 计算滞后互相关：`k* = argmax_k corr(x_i[t], x_j[t-k])`，`k ∈ [-K, K]`；
  2. 显著性筛选：仅当 `|corr(k*)| ≥ τ` 且 `|k*| ≥ k_min` 时保留为有效样本对，否则归入"无显著关系"类；
  3. 滞后标签量化为离散 bins，并用以 `k*` 为中心的高斯邻域做**软标签**（降低噪声影响）。
- **模型**：通道表示池化得 `h_i, h_j` → `MLP([h_i; h_j; h_i⊙h_j; |h_i−h_j|])` → 两个输出头：
  (a) 滞后 bin 软回归（soft cross-entropy）；(b) 领先方向分类（i→j / j→i / 无显著）。
- **与现有工作区别**：Lag-Llama 把滞后当"输入特征"，CoST 的相位项只用于"区分季节模式"；
  本模块首次把**跨通道时序关系结构**本身作为显式预训练目标，使表示内部编码了 lead-lag 信息。
- **开销**：通道对 O(C²)；`C≤21` 时 ≈210 对，无压力；C 大时随机采样通道对。

### 3.5 S4 质量头（⑦ 缺失/置信度）★创新点
- **三态构造**（让"缺失"成为一等公民，区分"0"与"缺失"）：
  - **M（掩码缺失）**：随机 25% 时间点置 0 + 缺失指示符 =1；
  - **N（噪声注入）**：随机 10% 段注入高斯噪声，幅度等级 `q ∈ {1..4}`（σ_q 递进，按段分配），质量等级 = q；
  - **O（正常观测）**：其余。
- **输入编码**：数值嵌入 + 缺失状态嵌入（3 态）+ 质量等级嵌入（N 态时），加和/拼接后进入骨干。
- **任务与损失**：
  1. 重建被 M 掩码的点（MSE 仅计算 M 点，MAE 式）→ `L_recon`；
  2. 预测 N 段的质量等级 q（分类）→ `L_qpred`；
  3. `L_qual = L_recon + λ_q·L_qpred`。
- **学习信号**：模型必须学会"缺失≠0、低质量≠正常"，且质量嵌入可被下游利用
  → 异常检测更稳健、跨域更鲁棒。
- **可选扩展**（二期/消融）：MNAR 掩码模式（掩码概率依赖数值本身）→ 缺失机制感知。

## 4. 总损失与训练策略

```
L = w1·L_hier + w2·L_pat + w3·L_rel + w4·L_qual
```

- **权重**：默认采用同方差不确定性自适应权重（SimMTM 式），并报告固定权重的对照；
- **分阶段 warm-up**：先 S1+S2 → 逐步加入 S3 → S4（每流单独收敛 sanity check 后再联合）；
- **消融即开关**：主消融表 = 逐条移除每个语义流；补充消融 = 软标签/显著性阈值、质量等级数、滞后 bin 数。

- **预测**：ETT×4、Electricity、Weather、Traffic；horizon `{96,192,336,720}`，MSE/MAE。
- **分类**：SleepEEG、Epilepsy、FD-B、Gesture、EMG（SimMTM 5 数据集，域内+跨域）；可选 UEA 子集（SVM 协议，TS2Vec 式）。

- **零样本/跨域**：预训练语料 A（如能源+交通）→ 冻结编码器 + 线性探针，直接评估未见数据集 B（如 SWaT、UEA 子集）。

### 5.3 基线（统一骨干公平复现）
TS2Vec、TS-TCC、TF-C、CoST、SimMTM、TimesURL、Ti-MAE、PatchTST（监督参考上界）。

## 8. 风险与对策

| 风险 | 对策 |
|---|---|
| 四条流联合训练不稳定 | 分阶段 warm-up；自适应权重；每流单独验证后再联合 |
| S3 弱标签噪声（滞后互相关误判） | 显著性阈值 + 高斯软标签；先用 Lorenz-96 耦合合成数据验证模块有效性 |
| 单卡预算紧张 | 通道独立 + 参数 ≤5M + 数据集子集训练；全流程单卡可跑 |
| 创新点增益不达预期 | 防御性推进：每个创新点先在小闭环证明增益，再合并进全模型 |
| 实验周期过长 | 最小闭环优先（1 数据集 × 1 任务 × 单流消融跑通）再铺开 |

## 10. v0.1 实现备注（代码与论文方案的简化差异）

代码实现（`src/semts/`）对 §2–§3 的设计做了以下务实简化，均已在代码注释中标注，论文实验部分将逐一说明：

1. **两视图共用同一随机窗口**：TS2Vec 原文为两视图各采样不同重叠窗口；v0.1 改为 batch 共享一个窗口、
   两视图差异 = 输入增强（scale/shift/jitter）+ 独立采样的隐向量掩码，避免跨视图频率轴/时间轴对齐问题。
   （TS2Vec 式双窗口裁剪留待 v0.2。）
2. **实例对比改为序列级池化**：TS2Vec 原文实例对比逐时间戳计算（O(N²T) 计算量，N=B*C 时过重）；
   v0.1 用序列级池化向量的 NT-Xent（含通道身份判别），复杂度降为 O(N²)。
3. **S2 时域对比无动量编码器**：CoST 原文用 MoCo（动量编码器 + 队列）；v0.1 保留队列但 key 直接来自
   同一编码器的增强视图。
4. **S2 对比在序列级池化向量上进行**：CoST 原文在随机时间步 t 的表示上对比。
5. **S3/S4 的弱标签与监督信号来自完整窗口的原始输入**，而表示来自裁剪窗口（batch 内窗口共享几何）。
6. **S1 的视图 B 携带输入级增强**：上下文一致性（TS2Vec）与变换一致性（TS-TCC）在视图差异中混合，
   增强强度默认温和（σ=0.2）。
